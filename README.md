# Smart Attendance System (Java)

A desktop-based Smart Attendance System built using Java Swing,
integrating QR Code generation & camera-based scanning for automated attendance.

## Features
- Student management with roll number validation
- Weekly attendance tracking (12 weeks)
- QR Code generation per student
- Camera-based QR scanning using OpenCV
- Sorting using Quick Sort (Roll No / Name)
- CSV-based data persistence
- Color-coded attendance visualization

## Tech Stack
- Java
- Swing (GUI)
- Data Structures & Algorithms
- ZXing (QR Codes)
- OpenCV (Camera)
- File Handling (CSV)

## How to Run
1. Clone the repository
2. Add OpenCV native library
3. Run `SmartAttendanceSystem.java`
